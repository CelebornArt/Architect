# Architect implemented features

This is a granular inventory of the current project, checked against the active renderer (`workspace.ts`), HTML shell, Electron entry point, and the existing preview verification notes. **Implemented** means a usable local behavior exists; **Partial** means a basic version exists but does not yet match the full Notion interaction or data model. A menu label by itself is not counted as a working feature.

## Application and persistence

- **Implemented:** Collapsible left sidebar with an edge minimize/expand handle (`#sidebar-collapse-handle` and `Ctrl+\` shortcut persisted in localStorage); fullscreen writing mode keeps the sidebar available while toggling browser fullscreen and `#fullscreen-exit-pill`.
- **Implemented:** Modal dialogs support backdrop click-to-dismiss and `Enter` to save/apply (`#cover-dialog`, `#settings-dialog`, `#user-settings-dialog`, `#icon-dialog`, `#assets-dialog`, `#search-dialog`, `#lightbox-dialog`, `#asset-dialog`).
- **Implemented:** Browser-based workspace shell served from `index.html`.
- **Implemented:** Obsidian-inspired left Feature Switcher Rail (`#feature-rail`) with vertically centered larger SVG icons (`Notion mode`, `Dashboard`, `Boards`, `Inbox` with unread badge, `Search`, `Asset library`, `Trash`, and `User settings`) paired with an Obsidian-style explorer header in `#sidebar` (moving Admin-only Workspace settings out of the top-left Notion sidebar into `#dashboard-view` when `actingAsAdmin` is enabled); username, avatar, and storage status rows removed from the sidebar footer so only `User settings` (`[data-action="user-settings"]`) sits at the bottom.
- **Implemented:** User preferences (`userPreferences` persisted in workspace JSON + `@font-face` asset resolution) presented in an Obsidian-style two-pane categorized settings modal (`#user-settings-dialog`) with left search (`#user-settings-search`) and `General`, `Appearance`, `Toolbar`, `Files` (Local / Drive / Server save destinations), `Hotkeys` (searchable/filterable shortcut binder with live keystroke capture and runtime dispatch), and an empty `Plugin browser` roadmap placeholder.
- **Implemented:** Electron `BrowserWindow` shell with context isolation, Node integration disabled, external HTTPS links opened in the system browser, and validated page deep links opened in a new Architect window.
- **Implemented:** Build scripts for TypeScript/Electron, Windows desktop packaging, and macOS packaging configuration.
- **Implemented:** Version-2 workspace JSON model with page IDs, parent-page IDs, block IDs, timestamps, user records, and page metadata.
- **Implemented:** Migration from the older `notion-clone-pages` localStorage shape.
- **Implemented:** Debounced localStorage persistence and visible Saving / All changes saved indicator.
- **Implemented:** Workspace settings expose coordination & storage modes (defaulting to Local only + Local storage), solo sync / view-only mirror settings, acting Admin role toggle, workspace rename, and versioned JSON backup export/restore with schema validation and rollback protection.
- **Implemented:** Storage and coordination adapter ([storage.ts](../../storage.ts), [electron/main.ts](../../electron/main.ts), [electron/preload.ts](../../electron/preload.ts)) defaulting to **Local only** coordination and **Local storage**: Electron persists workspace JSON and the asset catalog (`assets.json`) with queued atomic writes plus full binary assets/previews in `userData/ArchitectData/` via custom `architect-asset://` streaming (with HTTP range seeking); browser mode stores full binaries in IndexedDB (`architect-local-assets-v1`). Local assets always preview at full resolution, while non-local Server/Drive assets support user-configured `smart-proxy` (byte-budget crisp WebP/JPEG encoding instead of blurry fixed-% thumbnails) or `download-all` local folder caching.
- **Implemented:** Cloud-drive file sync settings (`#settings-dialog`) and sidebar `Synchronize` button for local solo multi-device sync and **view-only mirrors** (`readOnlyMirror`), supporting folder pull/push with incremental binary `assets/`/`previews/` sync (Desktop) or browser File System Access (`showDirectoryPicker`) plus `http:`/`https:` JSON snapshot auto-pull on startup or every `X` minutes while locking editing (`todo`, `toggle`, `code`, properties, text) and blocking source writes.
- **Implemented:** Local Asset Management System (`#assets-dialog`, slash `/asset`, and Ctrl/Cmd+K search integration) tracking `fileType`, `category` (`music`, `sfx`, `3d model`, `concept`, `illustration`, `video`, `document`, `image`, `other`), admin-reassignable `creator`, `tags`, `metadata`, and storage mode (`local` | `drive-reference` | `server`), featuring interactive audio timeline scrubbing (`music`/`sfx`) with automatic player cleanup, video playback, full-size original downloads, validated `http:`/`https:` Drive references, missing-asset block relink recovery, and Notion-style double-click/menu fullscreen image lightbox (`#lightbox-dialog`).
- **Partial:** Team-hosted live collaboration server, real Google Drive OAuth API adapter (currently URL reference + desktop synced-folder adapter), and per-workspace Discord-style roles backend are not built yet.
- **Partial:** `workspace.ts` still uses `// @ts-nocheck`, while `storage.ts`, `icons.ts`, `board.ts`, `database.ts`, `toolbar.ts`, and `electron/` modules are compiled and type-checked by TypeScript (`tsconfig.json` & `tsconfig.electron.json`).

## Page editing

- **Implemented:** Create pages from the sidebar and with Ctrl/Cmd+N.
- **Implemented:** The first updated-app launch preserves a JSON backup of the previous workspace in local storage and replaces its pages with one blank `New hub`, as requested. Workspace settings can export that pre-reset backup.
- **Implemented:** Page navigation supports back/forward history buttons positioned to the left of `#breadcrumbs`, clickable ancestor breadcrumbs, and Alt+Left / Alt+Right keyboard navigation.
- **Implemented:** The page options menu toggles full-width layout and a live word count.
- **Implemented:** The page-wide editable container has no browser focus outline; block-level focus and hover cues remain available.
- **Implemented:** Programmatic focus on an empty editable block uses an invisible temporary text anchor so the caret lands after the list indentation; the anchor is stripped from persisted text and markup.
- **Implemented:** Create a child page with `/page`; a stable-ID clickable page link is inserted into the source page and the child appears in the outline.
- **Implemented:** Edit page title and page `Description` inside the collapsible Page properties panel; single-line title rejects Enter and flattens pasted line breaks.
- **Partial:** Member administration, trash workflow recovery, true multi-workspace access, live server collaboration, version history, and external database integrations.
- **Implemented:** Page link blocks navigate to their target page; page titles/icons are read from the current target record.
- **Implemented:** Add an editable trailing text block so pages retain an insertion point.
- **Implemented:** Enter splits a text block, continues bullet/numbered/to-do lists at the current indentation level, outdents empty indented list items one level per Enter before exiting to text, and exits flat empty list items to text; Tab / Shift+Tab indents and outdents single or multi-selected bullet, numbered, and to-do items (excluding toggle lists) with depth-cycled bullet glyphs (`•`, `◦`, `▪`), parent-scoped multi-level numbering (`1.`, `a.`, `i.`), and Backspace outdenting at start of indented lines; Backspace at flat block starts removes empty blocks or merges compatible blocks.
- **Implemented:** Empty text-block command hints show only on the active block. The editor-wide Ctrl/Cmd+A handler selects editable page text across blocks.
- **Implemented:** Blocks expose an external `.block-rail` (`+` insert control and `⠿` drag handle) positioned outside `.block-editor` so the caret never jumps into controls. Clicking `+` adds a block below, Alt-clicking adds one above, dragging a handle across a multi-block selection moves all selected blocks in order, and clicking the handle opens a Notion-style block menu with `Turn into` and `Color` (text & background swatches + `Last used`) hover flyouts, block-specific `Edit icon` (`callout` and `page_link`), column add/delete actions, shortcut hints, and a `Last edited` author/word-count footer.
- **Implemented:** Obsidian / Word-style configurable formatting ribbon (`toolbar.ts`, `#editor-toolbar`) with hover-triggered dropdowns, vertically centered `48px` centered-icon layout when docked `left`/`right`, separators, per-block alignment (`left`/`center`/`right`/`justify`), Headings (`Normal`, `H1`–`H6`, Toggle `H1`–`H3`), Lists, Callouts (accent-bar `Quote` + Obsidian `Note`, `Info`, `Tip`, `Warning`, `Important`, `Danger`, `Question`, `Example` cards), Font family + custom font upload, Text & Highlight colors (10 palette swatches, black default icons that update to the picked color and re-apply it on single click), Text options (`UPPERCASE`/`lowercase`/`Title Case`/`Small Caps`/`Superscript`/`Subscript`/`Code`/`Link`/`Embed`/`Inline math`/`Date`), Format painter, Clear formatting, non-database simple table insertion, and Fullscreen mode (`#fullscreen-exit-pill`).
- **Implemented:** Floating text-selection bar (`#selection-toolbar`) and right-click context menu on marked text expose all inline formatting actions plus 10 text colors and 10 highlight colors, saved safely via the extended inline HTML sanitizer (`SUP`, `SUB`, `data-text-color`, `data-bg-color`, `data-text-case`, `data-font`, `inline-math`).
- **Implemented:** Callout blocks and to-do items inherit the outer block-editor editability chain (with non-editable icon/checkbox controls, matching toggle lists) so text selection and deletion flow across lines starting on any list or callout; callout blocks support accent-bar quotes and Obsidian-styled typed callouts (`note`, `info`, `tip`, `warning`, `important`, `danger`, `question`, `example`) with editable persisted header titles (`.callout-title-chip`), clickable custom icons, and custom text/background colors.
- **Implemented:** Block drag reordering restores the previous scroll position after a drop, including when moving blocks upward.
- **Implemented:** Columns function as side-by-side blocks (`2`, `3`, `4`, `5+` columns) with matching 29px single-line height, top-aligned column headings, draggable dividers between every adjacent column, persisted relative widths, and full nested block lists (including nested columns). Deleting/Backspacing/moving the last block of a column removes that column (`3 -> 2`, unwrapping `2 -> 1`), dragging blocks or headings to the left/right edge of a block or column creates/adds columns side-by-side, and the block menu includes `Add column left`, `Add column right`, `Add column`, and `Delete column`.
- **Implemented:** Per-page `Ctrl/Cmd+Z` undo and `Ctrl/Cmd+Shift+Z` / `Ctrl+Y` redo across typing bursts, block operations, formatting, and column resizes.
- **Implemented:** The page icon renders beside the page title directly below the cover banner, with the page action bar (`Add cover` only when no cover exists, `Change icon`, `Add comment`, `Favorite`) positioned beneath the title while `Edit cover` lives at the bottom right of `.page-cover`.
- **Implemented:** Pages and blocks have stable deep links (`#page=<id>` and `#page=<id>&block=<blockId>`); opening a block link scrolls to the block and briefly highlights it.
- **Implemented:** Page actions use a right-click context menu with open in new tab, rename, duplicate, copy link, favorite, change icon, and delete; deleting a page removes its descendants and keeps at least one page. Rename still uses a prompt.
- **Partial:** Page delete is not a restorable trash workflow.
- **Implemented:** Cover editing uses a live crop stage showing the full-resolution image with a darkened surround, a banner-shaped crop frame reflecting the `.main-area` banner ratio cleanly flush beside the sidebar (`#page-cover-slot` without negative viewport overlap), pointer dragging to reposition, and a corner handle to zoom. Covers persist in the Asset Library (IndexedDB in browser / `architect-asset://files/` on Electron disk) and always resolve their full-resolution original across page reloads and re-crops.
- **Implemented:** Page icon selection (`#icon-dialog`, [icons.ts](../../icons.ts)) features `Emoji`, `Icons`, and `Upload` tabs alongside `Filter...`, random selection, `Remove`/reset, and a 10-color swatch dot picker for 64+ monochrome SVG icons (`arch-icon:<id>:<colorKey>`); custom vector icons, emojis, and uploaded images render uniformly across the outline, tabs, page headers, callout blocks, search results, boards, and database rows.
- **Implemented:** Miro-like interactive infinite canvas **Boards** ([board.ts](../../board.ts)) triggered via `/board` (converting an empty page in place into `pageKind: 'board'` or creating a child board page) and `/board inline` (inserting a `board_view` block with bottom & right edge drag-resize handles persisted on `boardHeight`/`boardWidthPct`), supporting pan/zoom dot-grid viewport, sticky notes, text boxes, shapes (`rect`, `rounded`, `circle`, `diamond`), freehand pen drawings, dynamic SVG connectors, page-link cards, drag-and-drop & Asset Library insertion for all file types, and directly playable HTML5 audio cards inside boards.
- **Implemented:** Interactive **Inbox** notifications panel (`#inbox-view`, `[data-app-mode="inbox"]` & `[data-action="updates"]`) collecting comments, replies, resolve/reopen updates, and workspace alerts with unread count badges (`#rail-inbox-badge` / `#sidebar-inbox-dot`), `Unread`/`All`/`Comments`/`Activity` filters, mark-read/clear actions, and click-to-jump navigation to the target page/comment.
- **Implemented:** Page comments, block comments, and inline marked-text comments persisted per page (`page.comments` and `<mark class="comment-mark">`), supporting text selection via floating toolbar (`💬 Comment`), right-click block context menus and `Ctrl/Cmd+Shift+M`, top-of-page commenting (`💬 Add comment`), always-visible stacked comment cards at the far right margin (shrinking only crowded stack overflows or narrow viewports to compact `💬` pills), and a topbar Comments drawer (`Open` / `Resolved` / `All`) with threaded replies, inline editing, deletion, and resolve/reopen actions.
- **Implemented:** Collapsible Page properties are collapsed by default on normal pages behind a disclosure arrow beside the `Page properties` label (hiding the `Description` field, `+ Add a property` button, custom property fields, and helper text until expanded). Database row pages display expanded shared `Database properties` synced back to their parent database alongside normal page content.
- **Implemented:** Full-page Databases (`/database`, converting an empty page into a database page or creating a child database page when the current page already has content), inline Database references (`/database inline` and `Linked view of database`), relational schema properties (`Title`, `Text`, `Number`, `Select`, `Multi-select`, `Status`, `Date`, `Person`, `Files & media`, `Checkbox`, `URL`, `Email`, `Phone`, `Relation`, `Rollup`, `Formula`, `Created time`/`by`, `Last edited time`/`by`), 8 shared views (`Table`, `Board`, `List`, `Gallery`, `Calendar`, `Timeline`, `Chart`, `Feed`), live Filters, Sorts, Grouping, Property visibility/order, Column width resizing, Summary calculations (`Count`, `Sum`, `Average`, `Median`, `Min`, `Max`, `Range`), row Templates, and synchronized `Side peek` / `Center peek` / `Full page` row drawers ([database.ts](../../database.ts)).

## Workspace outline and navigation

- **Implemented:** Separate Favorites and Workspace Pages outline groups.
- **Implemented:** Page rows navigate on click; disclosure arrows independently expand/collapse nested pages.
- **Implemented:** Child-page nesting comes from `parentId`; the expanded page IDs are retained in workspace state.
- **Implemented:** Page row menus open on click, right-click, or the keyboard context-menu key and offer open in new tab, rename, duplicate, copy link, favorite, change icon, and delete. Right-click is captured so the browser menu does not appear.
- **Implemented:** Page rows, page links, breadcrumbs, Quick Find results (`Ctrl+Click`/`Ctrl+Enter`), and database rows open in the active tab on click, or in an in-app **Architect tab** (`#app-tab-bar` with persisted open tabs, per-tab history, `＋` new tab button, `Ctrl/Cmd+T`, middle-click close, pin/duplicate/close actions) on `Open in new tab`, Ctrl/Cmd-click, or middle-click—never opening a new browser tab. Right-clicking anywhere in the application suppresses the browser context menu and renders a custom context-aware menu (`Cut`/`Copy`/`Paste`/`Select all`, tab actions, sidebar/page actions, database row/column actions, link/media actions, and block actions).
- **Implemented:** Search dialog ranks title matches above body matches, shows a matching text preview, supports arrow-key selection and Enter to open, and displays an empty-result message; Ctrl/Cmd+K and Ctrl/Cmd+P open it and Escape closes it.
- **Partial:** Workspace list shows only the current workspace; membership and switching are not modeled.
- **Partial:** Search covers page titles and top-level block text, not all properties, nested data, or assets.

## Text blocks, Markdown, and references

- **Implemented:** Text, Heading 1–6 (`h1`–`h6`), bulleted list, numbered list (per-list reset), to-do, toggle list (`>> `), toggleable headings (`># `–`>###### `, `/toggle heading 1`–`3`, and block-menu toggle), quote, callout, divider, and multi-line code (`Enter` inserts newline, `Ctrl/Cmd+Enter` exits) renderers, with persisted nested blocks inside toggles and columns, list markers aligned to normal text start (`27px`), and `cursor: text` on empty-block placeholders.
- **Implemented:** Line-start shortcuts for `#`–`######`, `-`, `*`, `+`, `[]`, `>`, `1.` when followed by Space, plus divider conversion (`---`, `___`, `***`) on both `Space` and `Enter` (moving focus onto a text line below the divider). `>` converts to Quote. Bulk paste parses common heading (`h1`–`h6`), bullet, numbered, checklist, quote, and divider lines, plus inline emphasis/code/link syntax (while pasting inside code blocks preserves plain text).
- **Implemented:** Inline `**bold**`, `*italic*`, `~~strikethrough~~`, and `` `code` `` convert while typing character-by-character and save as sanitized inline HTML.
- **Implemented:** Ctrl/Cmd+B, Ctrl/Cmd+I, and Ctrl/Cmd+U apply browser editing commands and save the resulting markup.
- **Implemented:** Inline HTML sanitizer retains a small formatting/link allowlist and filters unsafe link protocols.
- **Partial:** Markdown paste conversion covers common syntax but does not yet match Notion's full paste conversion or rich clipboard behavior.
- **Partial:** `@` suggestions include pages and sample people; `[[` suggestions include pages. Suggestions filter live and support Enter/Tab/arrow selection.
- **Partial:** Selecting a reference preserves prefix text, but the reference becomes an adjacent block instead of an inline rich-text node; inline caret position and suffix text are not fully modeled.
- **Partial:** Page mentions render with the same icon-and-link presentation as page-link blocks; person mentions render as a mention chip.
- **Partial:** Rich-text DOM is stored as sanitized HTML on a block, not as a normalized rich-text run model; selection, paste, undo, and collaborative editing remain limited.

## Slash-command menu and block catalog

- **Implemented:** Slash menu filters command names/categories as the user types; matching ignores case, spacing, and punctuation so `/todo` matches “To-do list.”
- **Implemented:** Menu anchors near the active block, groups options into eight labeled sections with divider rules and per-option glyphs, scrolls within the viewport, and supports ArrowUp/ArrowDown, Enter/Tab, and Escape.
- **Implemented:** Dedicated `2 columns`, `3 columns`, `4 columns`, and `5 columns` commands create the requested number of evenly segmented, resizable, nestable column cells.
- **Implemented:** Text, headings, lists, to-do, toggle, divider, quote, callout, page, link-to-page, image upload, duplicate, delete, and move-to-page actions have basic insertion or state-change paths.
- **Partial:** Mention/Emoji opens a page/person menu; Emoji is not a separate emoji picker.
- **Partial:** Date/reminder inserts a date value; it has no reminder scheduling.
- **Partial:** PDF, file, bookmark, video, audio, and embed use URL prompts/card renderers; they do not provide a complete upload/embed workflow.
- **Partial:** Code block supports language selection, text editing, and copy; syntax highlighting is absent.
- **Partial:** Table persists editable headers, cell values, and added rows; no column controls, formulas, filters, or database relation exist.
- **Partial:** Table of contents links to headings; it does not dynamically model the full page outline beyond the current block list.
- **Partial:** Breadcrumb block navigates to ancestor pages.
- **Not exposed:** Standalone template/button insertion was removed from the slash catalog. Templates are reserved for future database features; legacy saved button blocks can still render.
- **Partial:** Equation/Math prompts for text and displays it; there is no mathematical typesetting editor in the block itself.
- **Partial:** Duplicate, delete, and move-to-page actions work through basic data changes; move uses a prompt and lacks robust cycle/permission handling.
- **Not implemented:** Imports, mentions/reminders scheduling, database Forms/Automations, and full Notion command parity.

## Other page controls and gaps

- **Implemented:** Page and block deep links use hash routes; browser tabs and desktop windows can open the same page target, and block links scroll to and highlight the linked block.
- **Implemented:** Favorite toggle is stored on each page and drives the Favorites group.
- **Implemented:** Page link and person/page mention IDs are stored as structured references.
- **Partial:** Share button reports a copied-link toast; it does not create a real share link or access permission.
- **Partial:** Binary asset quotas and multi-device binary conflict resolution remain minimal; cover picker assets and Asset Library share local/IndexedDB/Electron disk persistence and missing-asset block recovery (`Relink from library` / `Upload file`).
- **Implemented:** Mode-switching **Ribbon** (`#feature-rail`, `data-region="ribbon"` — `Docs`, `Dashboards`, `Asset library`, `Synchronize`, `Trash`, `User settings`) & mode-swapping **Sidebar** (`#sidebar`, `data-region="sidebar"`): keeps the full Docs explorer in Docs mode, swaps to 6 **Dashboards** sub-modes (`Notifications`, `User Dashboard`, 6-module role-gated `Admin Dashboard` with `Member manager`, `Role manager`, `Content manager` + `Files & save locations`, `Notification creator`, `Team overview`, and `Time tracking overview`, emptied `Time Tracking & Calendar`, `Tasks`, and `Scratchpad` with `#`..`#####` headings & destination picker to save inside a page or database), hides document chrome (`#app-tab-bar` and `.topbar`) in Dashboards, and keeps `WORKSPACES` (`#workspace-access`) + `+ Create new workspace` anchored at the bottom.
- **Implemented:** Scoped **Notifications** (`Dashboards -> Notifications`) trigger only when `@` tagged in comments or pages, when another collaborator replies to one of your comments, or when an Admin sends one via `Notification creator`; clicking outside comments deselects them cleanly with lower unselected highlight opacity.
- **Implemented:** Document-scoped formatting toolbar (`#editor-toolbar`): visible only on text Docs pages (hidden on Database pages, Board pages, and non-Docs Ribbon modes) with a leading minimize/expand arrow at the left (horizontal) or top (vertical).
- **Not implemented:** Member administration, server-backed multi-workspace sharing, live collaboration sync server, version history, and database automations.
